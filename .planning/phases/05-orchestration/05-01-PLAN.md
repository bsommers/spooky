# Phase 5: Orchestration, LLM, CLI

**Goal:** assemble the engine; same capabilities via library and CLI.

## Flow
```
input -> size cap -> PRE pipeline (confidentiality) -> retrieve exemplars -> buildPrompt
      -> LLM (retry) -> POST pipeline (style, confidentiality) -> banned-phrase check -> {text, trace}
```
Retrieval query = sanitized input (post-redaction). Prompt contains only redacted input.

## Contracts
- `withRetry(fn, {maxRetries, baseMs, sleep, isRetryable})`: retries 429/5xx/network; not 4xx other; throws `LlmError(attempts)`.
- `Engine` (src/engine.ts): `ingest, getProfile, listPersonas, listFilters, generate` per CONTRACTS surface table.
- CLI maps errors to exit codes in CONTRACTS.md; `--json` prints `{ok, text?, trace?, error?:{code,message}}`; stdout = result only, logs to stderr.

## Test matrix
| Tier | Case |
|---|---|
| unit retry | success first try; fail,fail,ok (2 retries) -> ok; 3 fails -> LlmError attempts=3; non-retryable 400 -> no retry; sleep called with 1x,2x base (fake sleep) |
| integration | happy path trace order = pre filters, llm, post filters; input w/ secret -> mock LLM received prompt without secret (assert on captured request); LLM output echoing a secret -> final text clean |
| integration | unknown persona / unknown author -> typed errors, LLM never called |
| integration | input > cap -> `InputTooLargeError`, no filter ran (spy) |
| integration | fail-closed filter throws -> no LLM call (pre) / no text returned (post) |
| integration | LLM returns empty string -> `LlmError` (not empty success) |
| integration | persona banned phrase survives -> trace entry flags it, text still returned |
| system CLI | `ingest` then `generate --json` exit 0, valid JSON; each error -> documented exit code; `--help` lists all 5 commands; stdin and `--file` input both work; no API key + real client selected -> exit 2 with clear message |
| parity | for each CONTRACTS surface row, an engine method and CLI command exist (test enumerates) |
| determinism | same input + mock LLM twice -> byte-identical result |
