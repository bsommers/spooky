# Phase 1: Foundation & contracts

**Goal:** buildable skeleton whose types are the seams for all later phases.
**Global constraints:** deps limited to PROJECT.md list; `strict`, `noUncheckedIndexedAccess`; ESM.

## Test matrix (written first)
| Tier | Case |
|---|---|
| smoke | `tsc --noEmit` passes; `import` of `src/index.ts` succeeds |
| unit | valid config loads; missing `llm.model` -> `ConfigError` naming `llm.model`; negative `chunk.size` rejected; unknown filter name in `filters.pipeline` rejected; empty persona map rejected; persona with duplicate key rejected |
| unit | every `GhostwriterError` subclass has stable `code` and survives `instanceof` after `JSON.stringify` of `.code` |
