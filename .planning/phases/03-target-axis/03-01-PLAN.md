# Phase 3: Target axis

**Goal:** audience personas and deterministic prompt assembly.

## Contracts
- `TargetManager(personas: Record<string,TargetPersonaConfig>)`: `get(key)`, `list()`, throws `UnknownPersonaError`.
- `buildPrompt({profile, exemplars: ScoredChunk[], persona, input, maxExemplarChars}): {system, user}`
- `findBannedPhrases(text, persona): string[]` (case-insensitive, literal, escaped).

## Test matrix
| Tier | Case |
|---|---|
| unit | get known / unknown (error `.valid` sorted) / list sorted by key |
| unit | persona key mismatch with map key rejected at construction |
| unit | prompt contains: author stats block, N exemplars in score order, every structuralMandate, banned phrases as prohibitions, input last |
| unit | zero exemplars -> section omitted (no empty header) |
| unit | exemplars exceeding `maxExemplarChars` truncated at chunk boundary, lowest score dropped first |
| unit | input containing text that mimics prompt headers/instructions stays inside delimited `<input>` block; delimiter present in input is neutralized |
| unit | same inputs -> byte-identical prompt (snapshot) |
| unit | `findBannedPhrases`: term with regex meta literal; case-insensitive; none -> `[]` |
| unit | profile numbers rendered with fixed precision (1 decimal) so snapshots don't drift |
