# Phase 10: UI foundation & theming (milestone v3)

**Goal:** an accessible, offline, themeable app shell served by the Phase 9 server; no feature screens yet beyond a themed kitchen-sink and shell nav.

## Component library decision
1. React Aria Components (Adobe): Apache-2.0, same as Spooky, no attribution friction.
2. Headless: all styling is ours via CSS custom properties, so two very different themes need no overrides fighting a built-in look.
3. Best-in-class a11y (keyboard, focus, ARIA, screen reader tested, i18n); fewer axe failures to fix.
4. Alternatives checked: Radix UI (MIT, fine, but lower-level and fewer composed widgets), MUI (MIT, strong opinionated look, heavy theming effort), Chakra/Mantine (MIT, own theming runtime that competes with our token system). None clearly better.
5. License check at execution: run a license audit (`license-checker`/`npm ls`) over `ui/` production deps; allow Apache-2.0, MIT, BSD, ISC, OFL fonts; fail on GPL/AGPL/unknown; record in `ui/THIRD_PARTY.md`.

## Theme contract
`ui/src/theme/contract.ts` exports the required token list (zod). A theme is one CSS file `themes/<id>.css` defining `:root[data-theme="<id>"] { --gw-* }` plus a manifest entry `{id, label, colorScheme: 'dark'|'light'}`; adding a third theme = drop one token file + manifest line, nothing else. Tokens: `--gw-bg, --gw-bg-raised, --gw-surface, --gw-border, --gw-text, --gw-text-muted, --gw-accent, --gw-accent-text, --gw-accent-2, --gw-danger, --gw-warning, --gw-success, --gw-focus-ring, --gw-glow, --gw-radius, --gw-font-display, --gw-font-body, --gw-font-mono, --gw-motion-scale, --gw-bg-art` (background layer image/gradient). Components read only `--gw-*`, never raw colors (stylelint rule enforces).

## Themes (see docs/UI-THEMES.md for values)
- **Black Cat:** charcoal/near-black, amber/gold accent evoking slit-pupil eyes (vertical slit motif in focus rings/active indicators), faint whisker lines, paw-print bullets, cat-silhouette watermark, moon + night haze gradients; restrained, no clutter. Original SVGs authored in-repo.
- **Tron Neon:** matches lumagrid's look (palette, Orbitron/Inter/JetBrains Mono, perspective neon grid + cyan glow). Extracted from the live site on 2026-11-14.

## Test matrix
| Tier | Case |
|---|---|
| unit | contract: every theme file defines every required token; unknown extra token fails; manifest ids unique |
| unit | contrast: parse token files; assert AA (text >= 4.5, large/UI/focus-ring >= 3) for each declared pair (text/bg, muted/bg, accent-text/accent, accent/bg for UI, danger/warning/success on surface) in both themes; failing pair fails the build |
| unit | theme switch: sets `data-theme` on `<html>`, persists to localStorage; storage throwing (private mode) -> still works; invalid stored id -> falls back to system preference |
| unit | default: no stored value + `prefers-color-scheme` mapped to a theme; `prefers-reduced-motion` -> `--gw-motion-scale:0`, no animation on grid/haze (matchMedia mocked) |
| component | ThemeSwitcher keyboard operable, labelled, announces change; shell nav landmarks |
| a11y | axe on shell + kitchen-sink in both themes: zero violations |
| visual | Playwright screenshots shell + kitchen-sink, both themes, fixed viewport, animations disabled, fonts loaded; baselines committed |

## Tasks
1. Scaffold `ui/` (Vite, React 18+, TS strict, Vitest, Testing Library, vitest-axe or jest-axe, Playwright). Separate `ui/package.json`; root scripts delegate (`ui:build`, `ui:test`); root package.json edits deferred to execution time (another agent owns it now).
2. Theme contract + engine (provider, hook, no-flash inline-free bootstrap: tiny same-origin `theme-init.js`, CSP-safe).
3. Token files for both themes; contrast test; `docs/UI-THEMES.md` kept in sync.
4. Black Cat art: logo, wordmark, icon set (nav, paw, whisker, moon, eye, copy, check, warning, gear, play), favicon set - hand-authored SVG, `currentColor`-based; Tron variants via tokens.
5. App shell with React Aria (Tabs/nav, Button, Select, Switch, Dialog, Tooltip), typed API client generated from OpenAPI types (no keys, token in memory only).
6. Self-hosted fonts (Orbitron, Inter, JetBrains Mono: SIL OFL 1.1, via `@fontsource-variable/*`; Black Cat display font: choose an OFL serif/sans, e.g. Cormorant or Fraunces, at execution with license file copied).
7. Static serving in `src/api/static.ts` with CSP; offline + license tests; `docs/UI.md`.

## Threat/failure model
Third-party fonts/CDNs would leak usage and break offline: banned by test. localStorage may throw: theme persistence is best-effort. Glow/animation can violate reduced-motion: tokenized motion scale tested. Contrast of neon-on-dark and amber-on-black verified numerically, not by eye.
