# Phase 4: Source axis

**Goal:** turn an author's corpus into a `StylometricProfile` plus retrievable exemplar chunks.

## Contracts
- `chunk(text, {size, overlap}): string[]` — boundaries: paragraph > sentence > hard cut; never empty chunks; `overlap < size` enforced.
- `extractProfile(authorId, displayName, text): StylometricProfile` — pure, deterministic.
- `HashEmbedder(dim=256)`: tokenized, lowercased, FNV hash into dim buckets, L2 normalized.
- `InMemoryVectorStore`: cosine, ties broken by chunk id ascending; `save/load` JSON.
- `SourceManager({store, embedder, confidentiality, chunkCfg})`: `ingest(authorId, name, text)`, `getProfile`, `listAuthors`, `retrieve(authorId, query, k)`, `remove(authorId)`.

## Test matrix
| Tier | Case |
|---|---|
| unit chunker | short text -> 1 chunk; exact size boundary; overlap respected; no mid-word cut when a space exists; one 5k-char sentence hard-cut; CRLF; empty/whitespace -> `[]`; emoji/surrogate pairs not split; `overlap>=size` -> ConfigError |
| unit stylometry | known sentence set -> exact avg length/stddev; hedges ("perhaps","might","I think") counted per 100 words; single sentence; no punctuation; non-English text doesn't crash (metrics degrade, no NaN/Infinity: assert `Number.isFinite`); empty -> `ProfileError` not NaN |
| unit embedder | deterministic; unit norm; empty string -> zero vector handled in cosine (score 0) |
| unit store | top-k order; k > size; unknown collection -> `[]`; upsert same id replaces; save/load round-trip; corrupt file -> typed error |
| integration | ingest 3 fixture authors -> profiles pairwise differ on >= 2 metrics; re-ingest same text -> identical profile; retrieve for author A never returns B's chunks |
| security | corpus with planted `AKIA...`/PEM -> zero matches in store dump (SRC-04) |
| unit | `remove` deletes profile + collection; ingest twice replaces, not appends |
| torture | 5MB corpus ingests < 5s (record number; set perf budget from the measurement) |

## Threat model
Corpus secrets -> redacted pre-store. Store file on disk is plaintext: documented, path configurable, `0600` perms. Accepted: hashed BoW retrieval is weak semantically; swap `Embedder` in v2 (interface is the seam).
