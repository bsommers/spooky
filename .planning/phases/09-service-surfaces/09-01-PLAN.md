## Design
- `Operation<I,O> = { name, description, input: ZodType, output: ZodType, mutates: boolean, handler(engine, input) }`; registry is an ordered array, the single declaration.
- Adapters: CLI command table derived from registry where flags are declarative; HTTP `POST /api/<name>` (reads `GET`); MCP tool per op; OpenAPI built by walking the registry with `z.toJSONSchema` (zod 4) into a 3.1 document.
- Error table `{code -> exitCode, httpStatus, mcpError}` in one file; tests assert every `GhostwriterError` code present.

## Threat/failure model
Local service with LLM key and a private corpus behind it: threats are drive-by browser requests (CORS/DNS rebinding/CSRF), network exposure, oversize/slow bodies, secret leakage through logs/errors, and prompt-injected agents calling MCP tools. Mitigations above; tools never accept paths; ingest is the only mutating tool and uses the existing state lock. Residual: any local process can reach a tokenless loopback server; docs recommend the token. package.json is owned by another agent while this spec is written: dependency additions (`@modelcontextprotocol/sdk`) happen at execution time.
