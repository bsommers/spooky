# Phase 7: AI-likeness scorer (milestone v2)

**Goal:** a deterministic, explainable [0,1] score plus a plug point for external detectors.

## Test matrix
| Tier | Case |
|---|---|
| unit | each feature in isolation: uniform-length text -> high burstiness-penalty; varied -> low; repeated n-grams; cliche density; empty text -> defined result (score 0.5, flag `insufficient_text`), text < 50 words flagged low-confidence |
| unit | score always in [0,1], finite, for 1k random strings (seeded) |
| unit | deterministic: same text twice identical; breakdown contributions sum to score (±1e-9) |
| unit | weights from config; weights not summing to 1 normalized; negative weight rejected |
| unit | ensemble: mean of adapters; adapter throws -> excluded and recorded; all fail -> local scorer only; adapter returns 1.2 or NaN -> rejected |
| unit | protected spans (code) excluded from features |
| calibration | on labeled corpus (>= 30 human, >= 30 AI samples, provenance noted per file): AUC >= 0.70 required to ship, actual value recorded in CALIBRATION.md; below that the plan fails, not the threshold |
| security | detector adapters get redacted text only (confidentiality runs first) |

## Tasks
1. Features (tests -> impl) · `--only features`
2. Scorer + breakdown · `--only scorer`
3. DetectorAdapter + ensemble · `--only ensemble`
4. Fixture corpus + `scripts/calibrate.ts` (AUC, histograms) · run, record in docs
5. CLI `ghostwriter score [--json] [--detector name]`; library `engine.score`

## Threat/failure model
A heuristic score is a proxy, not a detector verdict. Docs state measured AUC and that third-party detectors differ and change. External adapter calls send text off-box: opt-in only.
