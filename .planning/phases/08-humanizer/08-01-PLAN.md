# Phase 8: Humanizer loop (milestone v2)

**Goal:** bounded score-driven rewriting that lowers the AI-likeness score while preserving meaning.

## Loop
```
text -> score -> (score <= target?) yes -> done
                no -> pick 2 worst features -> targeted rewrite
                      (deterministic edits first: rhythm split/merge, cliche removal;
                       then LLM pass with author profile + feature instructions)
                   -> meaning guard -> confidentiality -> rescore
                   -> improved? keep : revert ; iteration++ < max -> loop
```

## Test matrix
| Tier | Case |
|---|---|
| unit guard | numbers, dates, proper nouns, quoted spans, URLs, code identical -> pass; changed number -> reject; dropped entity -> reject; added new number -> reject |
| unit loop | already below target -> 0 iterations; reaches target at iteration 2 -> stops; never reaches -> stops at max with best-scoring version, not last; rewrite worsens score -> reverted; guard rejects -> reverted and counted |
| unit | LLM failure in rewrite -> keep prior text, trace error, no throw (`onError: skip`) |
| integration | mock LLM scripted rewrites: final score < initial on fixture AI texts; trace has per-iteration score and feature deltas |
| security | secret introduced by the rewrite LLM -> removed by confidentiality pass before rescore |
| determinism | with mock LLM, identical runs byte-identical |
| calibration | across AI fixture corpus: report mean score before/after and guard-rejection rate in HUMANIZING.md with real numbers; if mean drop < 0.1, document honestly rather than tune the fixtures |

## Tasks
1. Meaning guard · `--only guard`
2. Deterministic rewrite steps · `--only rewrite`
3. LLM rewrite step (prompt built from profile + feature instructions) · `--only rewriteLlm`
4. HumanizeFilter (post stage, after Style, before final confidentiality) · `--only humanize`
5. CLI `generate --humanize [--target 0.3]`, `ghostwriter humanize <file>`; config `humanize: {targetScore, maxIterations}`
6. Docs with measured results per detector actually tested

## Threat/failure model
Rewrites can change meaning: guard + revert. Cost: <= maxIterations extra LLM calls, reported in trace. Accepted: no guarantee against any specific third-party detector; results are measured and published, including failures.
