# Phase 2: Filter pipeline + filters

**Goal:** pluggable async pipeline with two production filters, fixing the nine defects listed in PROJECT.md.

## Test matrix (written first)
### Pipeline (unit)
| Case | Expect |
|---|---|
| zero filters | text unchanged, empty trace |
| order A,B | B sees A's output; trace order A,B |
| stage filtering | `pre` filter not run in post stage |
| async filter w/ delay | awaited, `ms` >= delay |
| fail-closed throws | `FilterFailedError(filter=name)`; later filters not run |
| skip throws | trace `error` set, text = previous, later filters run |
| disabled via config | filter absent from trace |
| reorder via config | order follows config |
| register same name twice | throws at registration |
| filter returns non-string content | treated as filter error |

### Confidentiality (unit + security)
| Case | Expect |
|---|---|
| AWS `AKIA` + 16 | `[REDACTED:aws_key]` |
| two keys in one string | both redacted (CNF-02) |
| `ghp_`+36, `github_pat_`, `sk-`/`sk-ant-`, `xoxb-`, JWT (3 b64url segs), `Bearer abc.def` any case | redacted by type |
| full PEM block multi-line (RSA/EC/OPENSSH/PRIVATE) | header..footer removed, body gone |
| PEM header only, no footer (truncated) | redact from header to end of text (fail safe) |
| blocklist term with regex meta `Proj(X)+` | literal match, no throw |
| blocklist case-insensitive option | on/off both tested |
| overlapping blocklist terms `Acme`, `Acme Corp` | longest first, no partial remnant |
| custom regex invalid | throws at construction (`ConfigError`) |
| custom regex catastrophic `(a+)+$` on 50k `a` | completes < 200ms (cap input per rule / reject nested quantifiers at construct) |
| placeholder text already in input | idempotent |
| metadata | `{aws_key: 2}` counts only; assert no matched value in `JSON.stringify(trace)` |
| unicode homoglyph/zero-width inside key (`AK\u200bIA...`) | normalized then redacted |
| empty string / 1MB string | no error / completes < 1s |
| **leak corpus** (`tests/fixtures/leaks/`, 40+ samples incl. secrets in code fences, URLs `?token=`, JSON, env files) | zero residual matches of any pattern |

### Style filter (unit)
| Case | Expect |
|---|---|
| `Furthermore, we ship.` | `We ship.` (re-capitalized) |
| mid-sentence phrase | removed, single space, no orphan comma |
| replacement entry `delve into` -> `dig into` | casing preserved (`Delve into` -> `Dig into`) |
| same phrase 3x, called twice | identical results (no `lastIndex` state) |
| persona extra banned phrases via ctx | removed |
| phrase inside ``` fence / `inline` / URL | untouched |
| 6 sentences within ±15% length | split/merged per rule; deterministic; output equal on rerun |
| profile absent | rhythm step skipped, trace metadata `rhythm: skipped` |
| text with only banned phrase | returns empty string, no throw |
| markdown bullets/newlines | preserved (only collapse runs of spaces/tabs, not `\n`) |

### Torture
Random 10k strings x 200 runs through full pre+post: never throws, idempotent for confidentiality, protected spans unchanged (seeded PRNG).

## Threat & failure model
| Risk | Mitigation |
|---|---|
| Redaction miss leaks secret to LLM provider | pre-stage fail-closed + corpus test + post-stage re-run |
| ReDoS via custom rule | construct-time validation + length cap per rule |
| Filter bug corrupts code samples | protected spans |
| Trace logs leak secrets | metadata types restricted to number/string/boolean; test greps trace |
| Accepted risk | novel secret formats and non-pattern PII (names, addresses) are not detected; v2 NER filter |
